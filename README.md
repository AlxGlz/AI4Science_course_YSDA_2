# Проверка фильтрации фотоплетизмограммы

[порождено: Codex]

Учебный проект ДЗ2: сравнение сырого зашумлённого сигнала, скользящего среднего
и фильтра Баттерворта по ошибкам амплитуды и времени двух пиков.

## Состояние проекта

- **Этап:** подготовка к первой сессии Goose.
- **Готово:** методика, инструкции агенту, CSV данных и исходные разделы отчёта.
- **Ещё не выполнено:** контрольные сигналы и допуски, верификатор, код и прогоны эксперимента.
- **Следующий шаг:** поручить Goose подготовку контрольных сигналов и численных допусков.
- **Условия продолжения:** согласовать допуски до экспериментальных прогонов; исходные данные сохранять неизменными.

| Путь | Содержание |

В проекте только синтетические данные. Генератор и приватные записи пациентов
в него не перенесены. Для подбора и итоговой проверки выделено по 24 эталона;
все пять реализаций одного эталона относятся к одной части.

## Что появится при реализации

- `src/ppg/` — вычислительные функции; `checks/` и `verify.py` — верификатор.
- `run_experiment.py` — подготовка, тестовый прогон, подбор параметров и основной прогон.
- `plot_comparison.py` — графики сравнения сигналов.
- `results/` — таблицы, параметры и графики отдельных этапов.
- Дневник работы, `SUBGOALS.md` и `ATTEMPTS.md` — ход работы, подцели и попытки.
- `requirements.txt` и `requirements-lock.txt` — зависимости и точные версии.

Это планируемые части, а не уже выполненная работа. После их создания агент
обновляет эту карту ссылками на реальные файлы.

## Воспроизведение

Версии пакетов и команды для Windows и macOS заданы в
[§4 методики](METHOD.md#4-код-и-окружение), порядок этапов — в
[§6](METHOD.md#6-этапы-эксперимента). Пока скрипты не реализованы, эти команды
являются инструкцией для разработки и не могут быть запущены.
