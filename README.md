# Проверка фильтрации фотоплетизмограммы

[порождено: Codex]

Учебный проект курса ШАД «ИИ-ассистенты в естественно-научных исследованиях»,
ДЗ2 «Проверка». Исследуем, как фильтрация влияет на измерение амплитуды и времени
двух пиков фотоплетизмограммы (ФПГ) — систолического и диастолического.
Сравниваем сырой зашумлённый сигнал, скользящее среднее и фильтр Баттерворта.
Код сопровождается верификатором: тестами на свойствах, контрольными сигналами
и демонстрацией обнаруженной ошибки.

**Начать с результатов:** [отчёт](REPORT.md) ·
[краткий PDF](results/main/report.pdf) ·
[таблицы итоговой проверки](results/main/summary.md) ·
[графики](results/main/figures/index.md).

## Результат

На данных для подбора выбраны Баттерворт с параметром `N=4`, полосой 0,50–20 Гц
и скользящее среднее с окном 11 отсчётов. На итоговой проверке Баттерворт дал
меньшие средние ошибки, но один ожидаемый второй пик не был найден.
Итог — **частичное улучшение**. Сравнение по 15 полным парам эталонов
продолжено с разрешения пользователя; подробности и ограничения — в
[разделах 5 и 8 отчёта](REPORT.md).

Данные синтетические: 48 эталонов по 60 секунд при 320 Гц, по пять шумовых
реализаций — 240 входов. Для подбора и итоговой проверки выделено по 24 эталона;
все реализации одного эталона остаются в одной части. Начала волн и наличие
второго пика известны из разметки. Выводы относятся к этому набору и условиям
эксперимента; перенос на реальные записи не проверялся.

## Проверка и запуск

Нужны Git и Python **3.13.14**. Команды для Windows PowerShell:

```powershell
git clone https://github.com/AlxGlz/AI4Science_course_YSDA_2.git
cd AI4Science_course_YSDA_2
py -3.13 --version  # ожидается 3.13.14
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe verify.py
```

Успешный верификатор возвращает код 0; последний сохранённый прогон —
90 пройденных проверок. Пример обнаружения ошибки и её исправления — в
[разделе 6 отчёта](REPORT.md) и [журналах проверки](results/verify/).

Повторный расчёт с уже сохранёнными настройками, из корня проекта:

```powershell
.\.venv\Scripts\python.exe run_experiment.py prepare
.\.venv\Scripts\python.exe run_experiment.py main
.\.venv\Scripts\python.exe plot_comparison.py --results results/main
```

Команды обновляют соответствующие папки в `results/`. Для `main` файл
`results/select/run.json` должен совпадать с версией в Git.
Полный цикл с тестовым прогоном и новым подбором описан в
[METHOD.md, §4 и §6–7](METHOD.md): после `select` настройки фиксируются
коммитом до `main`. Там же приведены команды для macOS; работа на macOS
пока не проверена.
