# Проверка фильтрации фотоплетизмограммы

[порождено]

Учебный проект ДЗ2: сравнение сырого зашумлённого сигнала, скользящего среднего
и фильтра Баттерворта по ошибкам амплитуды и времени двух пиков.

## Состояние проекта

- **Этап:** проверки §5 согласованы и внесены в методику; следующий этап —
  верификатор `checks/` и `verify.py`.
- **Готово:** методика, инструкции агенту, CSV данных, исходные разделы отчёта;
  код подготовки проверок (`design/`), сводка с ожидаемыми ответами и
  допусками, исследование краевых эффектов (`results/design/`),
  дневник, подцели и попытки. Контрольные сигналы, численные допуски и
  параметры синусоид внесены в §5 `METHOD.md` (согласовано 2026-11-08 23:35).
- **Ещё не выполнено:** верификатор `checks/` и `verify.py`, код эксперимента
  `src/ppg/`, скрипты этапов, прогоны, графики, `REPORT.md`.
- **Следующий шаг:** реализовать `checks/` и `verify.py` по §5: контрольные
  сигналы CTRL-W1…W6, проверки свойств, независимая АЧХ, плюс демонстрация
  намеренной ошибки (замена 320 на 250) с сохранённым выводом до и после.
- **Действующие ограничения:** окно оценки оставлено 5–55 с (§2 не менялся);
  систематика по A2 до 3,51 % у волн 54–55 с (f_low = 0,10 Гц, f_high = 3 Гц,
  N = 4) известна и учитывается при трактовке подбора. Допуски и смысл проверок
  после согласования не подгоняются под результат; изменение критерия требует
  отдельного согласования. Исходные данные сохраняются неизменными.
- **Окружение:** `.venv/` ещё не создано (§4 методики). Подготовка выполнена
  системным Python 3.13.14 с NumPy 2.5.2 и SciPy 1.18.1 — версии совпадают с §4;
  `requirements-lock.txt` и `pip check` появятся вместе с окружением.

## Что появится при реализации

- `src/ppg/` — вычислительные функции; `checks/` и `verify.py` — верификатор.
- `run_experiment.py` — подготовка, тестовый прогон, подбор параметров и основной прогон.
- `plot_comparison.py` — графики сравнения сигналов.
- `results/prepare/`, `results/test/`, `results/select/`, `results/main/` — таблицы,
  параметры и графики этапов.
- `requirements.txt` и `requirements-lock.txt` — зависимости и точные версии.

Это планируемые части, а не уже выполненная работа. После их создания агент
обновляет эту карту ссылками на реальные файлы.

## Воспроизведение

Версии пакетов и команды для Windows и macOS заданы в
[§4 методики](METHOD.md#4-код-и-окружение), порядок этапов — в
[§6](METHOD.md#6-этапы-эксперимента).

Подготовка проверок §5 (не требует `.venv/` и не читает `data/`):

```powershell
# Windows
python design\run_design.py
```

```bash
# macOS
python3 design/run_design.py
```

Запись пересчитывает `results/design/` заново; длительность около 9 с.
Остальные команды станут доступны после реализации скриптов.
