## 3. Проверка фильтра на синусоидах: параметры и допуски

- Частота дискретизации 320 Гц, амплитуда 1,0, float64; длительность 300 с; окно измерения 60–240 с.
- Набор частот, Гц: 0.05, 0.1, 0.2, 0.5, 1, 2, 4, 8, 12, 20, 50.
- Ожидаемое усиление — квадрат модуля однопроходной АЧХ (`design/filter_reference.py`), ожидаемая фаза — 0.
- Сверка формулы с `scipy.signal.sosfreqz` на той же сетке: максимальное относительное расхождение 1,31e-10. Формула подтверждена независимо от проверяемого кода.
- Сверку нельзя делать через `scipy.signal.freqz`: с двумерной матрицей SOS он трактует её как MIMO-фильтр (для полосы 0,5–5 Гц, N = 4 на 1 Гц возвращает 3,0 вместо 0,9999). Нужен `sosfreqz`.
- Худшее расхождение формулы и измерения во временной области: 2,41e-07 относительно усиления в полосе; в глубокой стоп-полосе абсолютный пол измерения ~1e-11, поэтому допуск там задан абсолютной частью правила 1e-9.

### 4.3 Вывод по отступу 5 с

1. На синусоиде с частотой нижнего среза 0,10 Гц отступ 5 с **недостаточен**: отклонение от установившейся синусоиды при 5 с составляет 4.58 % при N = 2 и 19.45 % при N = 4. Для 1 % нужно 8.6–17.1 с, для 0,1 % — 14.5–27.5 с.
2. В метрике §2 (амплитуда от уровня начала волны того же сигнала) медленный краевой сдвиг уровня почти сокращается: на волнах 5–10 с вклад не выше 0.14 % для A1 и 0.78 % для A2; в середине записи (20–50 с) — не выше 0.103 % для A1.
3. Остаётся правый край: у волн, начинающихся на 54–55 с, отклонение A2 достигает 3.51 % в худшей настройке (f_low = 0,10 Гц, f_high = 3 Гц, N = 4), где полоса уже сильно искажает форму импульса. Для A1 во всём окне 5–55 с вклад не выше 0.14 %.
4. Поэтому отступ 5 с **достаточен для A1** и **на грани для A2**: смещение до 3,5 % одного порядка с порогом 5 % в §7 и зависит от настроек, то есть может смещать подбор. Рассматривались два варианта: оставить 5 с и учитывать смещение как известную систематику либо увеличить отступ до 15 с (окно 15–45 с, около 30 волн), при котором вклад края не выше 0.035 % для A1 и 0.221 % для A2. **Решение пользователя 2026-11-08 23:35 +02:00: оставить 5 с** (окно 5–55 с); §2 не меняется, систематика по A2 до 3,51 % у волн 54–55 с в настройке 0,10/3,0/N=4 фиксируется как известная и учитывается при трактовке подбора и правила §7.
5. Для проверок, где отфильтрованный сигнал сравнивается с теоретической синусоидой (усиление и фаза §5), отступ 5 с **непригоден**: там используется 60 с, как в разделе 3.
6. Дополнительное требование к верификатору: проверка сдвига уровня (уровень из другого сигнала) обязательна, иначе пункт 2 перестаёт действовать.

## 5. Что ещё обнаружено при подготовке

- Узкая полоса сильно меняет форму контрольного импульса: при f_high = 3 Гц и N = 2 установившаяся амплитуда первого пика ниже, чем у нефильтрованной волны, на 41.7 %. Это свойство контрольного импульса длительностью ~200 мс, а не результат эксперимента; на данных его нужно проверять отдельно.
- `padlen` по умолчанию у `sosfiltfilt` равен 15 отсчётов (46.9 мс) и на отступ 5 с не влияет: переходный процесс задаётся полюсом нижней частоты среза, а не длиной дополнения.
- Ошибки времени на периодической записи при обработке вперёд-назад не возникают (сдвиг индекса пика 0 отсчётов), поэтому метрика E_t на чистых периодических сигналах не чувствительна к краю; чувствительна метрика амплитуды.
